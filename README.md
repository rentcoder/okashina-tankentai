# おかしな探検隊 🧭

家族で１日５分。別々の時間に準備して、夕食時に冒険の絵日記を読むスマホ向けWebゲームです。

公開URL: https://okashina-tankentai.rentcoder.workers.dev

## 最初の版でできること

- 家族の家を作り、最大８人のキャラクターを登録
- 各自のスマホ、共有スマホの両方に対応
- 10分・１回限りのQR招待。参加は親の承認後に成立
- 既存キャラクターを別端末に引き継ぐ招待
- ６種類の持ち物から選び、７種類の冒険へ。日本時間18時に結果確定
- 各自の絵日記帳を月・日付で閲覧。参加できなかったメンバーも登場
- 宝物図鑑、家の８つの飾り場所。片づけても取得記録・絵日記は残る
- 漢字のルビ、スマホ向けレイアウト、ホーム画面用manifest

## 構成

Cloudflare Workers（API・静的配信）+ D1（SQLite）。GitHubはコードの保管先です。GitHub Pages自体に、この用途のデータベース機能はありません。秘密情報・家族のデータ・実際の招待URLはリポジトリに含めません。

フロントエンドはJavaScriptとCSS、QR生成はqrcode、端末内での読み取りはjsQR。カメラ映像は送信しません。外部AI・広告・アクセス解析は使用しません。

## ローカル開発

Node.js 22以上（検証は24）。

```sh
npm ci
npm run build
npm run db:local
npm run dev
```

表示先: http://localhost:8787 。QRの実機カメラにはHTTPSが必要です。

```sh
npm test
npx playwright install chromium
node tests/browser.mjs
```

ブラウザテストはポート8787のローカル開発サーバーを使います。本番環境では実行しないでください。テスト用の家族だけを作成します。APIテストは独立した一時D1で実行します。

## Cloudflareへ公開

1. Cloudflare APIトークンを環境変数 `CLOUDFLARE_API_TOKEN` に設定。対象アカウントに `D1: Edit` と `Workers Scripts: Edit` が必要です。アカウントを自動検出できない場合は `CLOUDFLARE_ACCOUNT_ID` も設定。
2. `npx wrangler d1 create okashina-tankentai` を実行。
3. 返されたdatabase_idを `wrangler.jsonc` に設定する。このリポジトリには現在の公開先のIDが設定済みなので、別アカウントへの導入時は置き換える。
4. `npm run db:remote` でスキーマを適用。
5. `npm run deploy` で公開。

トークンをファイルに書く場合は `.dev.vars` などgitignore対象のみを使用してください。コミットしないでください。CIはテストとビルドのみで、勝手にデプロイしません。

## データとアクセス制御

- 家族IDは、HTTP-only / SameSite=Strict Cookieのサーバーセッションから決定。クライアント指定の家族IDは信用しません。
- 個人端末は自分のキャラクターだけで操作。共有端末は家族のキャラクターを切り替えられます。
- 招待・承認・端末解除・共有設定は、親の６〜12桁のPINで10分間だけ操作可能。
- PINはPBKDF2-SHA256（100,000回）で保存。失敗５回で10分停止。
- 招待トークン、参加待ちの確認キー、セッショントークンはSHA-256ハッシュのみ保存。
- 招待は10分・１回限り。承認前に家族データは返しません。承認済みでも受け取り前なら取り消せます。
- CookieはHTTPSでSecure。書き込みには同一Originを要求。CSPで外部スクリプト・埋め込みを制限。
- 家からの片づけは飾ったキャラクターだけが可能。絵日記内の宝物情報を取得記録として使うので記録は消えません。

## ベータ版の制限

- 冒険の確定は18時以降に誰かが画面を開いた時点で実行します。18時のプッシュ通知はありません。準備した過去日分も、次回アクセス時に確定します。何もしなかった不在日の記録は作りません。
- 最初は７つの場所を日替わりで巡ります。シナリオは `src/stories.js` に追加できます。無限生成はしません。
- セッションは30日間です。全端末のCookie消去・セッション失効、PINの紛失に対する自動復旧は未実装です。一般向け本格公開前にアカウント復旧・エクスポート・家族データ削除を追加する予定です。
- メンバー単位の削除・並べ替え、時間帯設定、音声読み上げ、オフライン遊び、ネイティブストア配信は未実装。
- 家族内の絵日記は相互に閲覧できます。個人の秘密の日記としては扱いません。
- 物理スマホでのカメラ許可、iOS/Android双方の実機確認は別途必要です。
