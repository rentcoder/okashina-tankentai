# おかしな探検隊 🧭

家族で１日５分。別々の時間に準備して、夕食時に冒険の絵日記を読むスマホ向けWebゲームです。

公開URL: https://okashina-tankentai.rentcoder.workers.dev

## 最初の版でできること

- 家族の家を作り、最大８人のキャラクターを登録
- 各自のスマホ、共有スマホの両方に対応
- 10分・１回限りのQR招待。参加は親の承認後に成立
- 既存キャラクターを別端末に引き継ぐ招待
- 冒険ごとに異なる６種類の持ち物から選び、８種類の冒険へ。日本時間18時に結果確定
- 各自の絵日記帳を月・日付で閲覧。参加できなかったメンバーも登場
- 宝物図鑑、家の８つの飾り場所。片づけても取得記録・絵日記は残る
- 漢字のルビ、スマホ向けレイアウト、PWAインストールとオフライン案内
- オリジナルの水彩画タッチのキービジュアル
- ８冒険の出発前・結末の挿絵と、持ち物別48場面の絵日記
- 宝物８種・新しい持ち物48種の専用画像（従来の６種も過去の日記用に保持）（取得済みの宝物にも反映）

## スマホにインストール

- Android（Chrome）: 画面下部の「ホームがめんにおく」からインストール。表示されない場合はブラウザのメニューから「アプリをインストール」。
- iPhone / iPad（Safari）: 共有 →「ホーム画面に追加」。対応OSで「Webアプリとして開く」が表示されたらオン。
- パソコン（Chrome / Edge）: アドレスバーのインストールボタン。

初めての場合は、インストール後に家を作成することを推奨します。ブラウザとインストール済みアプリでログイン状態が共有されない端末では、他の家族の端末から既存メンバーの「つづきから」のQR招待を使ってください。

オフラインでは専用の案内画面を表示します。冒険・絵日記・宝物の利用には通信が必要です。Service Workerがキャッシュするのは公開のオフライン案内だけで、家族のAPIレスポンス・招待URLは保存しません。更新は次のアプリ起動時に反映され、操作中に強制再読み込みしません。

キービジュアルと冒険の挿絵は本プロジェクト用に生成したオリジナルのイラストです。冒険ごとに水彩・紙のコラージュ・コミカル調などを使い分けます。冒険の結末には５コマのぱらぱら絵本を用意しています。基本0.5秒間隔、見せ場は少し長めにし、最後のコマを３秒表示して自動ループします。停止・再再生も可能です。

## 構成

Cloudflare Workers（API・静的配信）+ D1（SQLite）。GitHubはコードの保管先です。GitHub Pages自体に、この用途のデータベース機能はありません。秘密情報・家族のデータ・実際の招待URLはリポジトリに含めません。

フロントエンドはJavaScriptとCSS、QR生成はqrcode、端末内での読み取りはjsQR。カメラ映像は送信しません。外部AI・広告・アクセス解析は使用しません。

## ローカル開発

Node.js 22以上（検証は24）。

```sh
npm ci
npm run build
npm run db:local
npm run dev
```

表示先: http://localhost:8787 。QRの実機カメラにはHTTPSが必要です。

```sh
npm test
npx playwright install chromium
node tests/browser.mjs
```

挿絵のブラウザテストは、ポート8788のローカルサーバーで `node tests/art-browser.mjs` を実行します。テスト用API応答を使い、全冒険×６持ち物の選択・過去記録のフォールバック・画像の読み込み・モバイル表示を確認します。本番データは作成しません。

PWAテストは `npm run dev -- --port 8788` を別ターミナルで起動してから `npm run test:pwa` で実行します。インストール条件・アイコン・案内・オフラインと再接続・APIキャッシュ除外を確認します。

ブラウザテストはポート8787のローカル開発サーバーを使います。本番環境では実行しないでください。テスト用の家族だけを作成します。APIテストは独立した一時D1で実行します。

## Cloudflareへ公開

1. Cloudflare APIトークンを環境変数 `CLOUDFLARE_API_TOKEN` に設定。対象アカウントに `D1: Edit` と `Workers Scripts: Edit` が必要です。アカウントを自動検出できない場合は `CLOUDFLARE_ACCOUNT_ID` も設定。
2. `npx wrangler d1 create okashina-tankentai` を実行。
3. 返されたdatabase_idを `wrangler.jsonc` に設定する。このリポジトリには現在の公開先のIDが設定済みなので、別アカウントへの導入時は置き換える。
4. `npm run db:remote` でスキーマを適用。
5. `npm run deploy` で公開。

トークンをファイルに書く場合は `.dev.vars` などgitignore対象のみを使用してください。コミットしないでください。CIはテストとビルドのみで、勝手にデプロイしません。

## データとアクセス制御

- 家族IDは、HTTP-only / SameSite=Strict Cookieのサーバーセッションから決定。クライアント指定の家族IDは信用しません。
- 個人端末は自分のキャラクターだけで操作。共有端末は家族のキャラクターを切り替えられます。
- 招待・承認・端末解除・共有設定は、親の６〜12桁のPINで10分間だけ操作可能。
- PINはPBKDF2-SHA256（100,000回）で保存。失敗５回で10分停止。
- 招待トークン、参加待ちの確認キー、セッショントークンはSHA-256ハッシュのみ保存。
- 招待は10分・１回限り。承認前に家族データは返しません。承認済みでも受け取り前なら取り消せます。
- CookieはHTTPSでSecure。書き込みには同一Originを要求。CSPで外部スクリプト・埋め込みを制限。
- ８か所は机・窓辺・冷蔵庫などに分かれ、家族の宝物を自分の宝物で置き換えて場所を取り合えます。何も置かずに片づける操作は飾ったキャラクターだけが可能。絵日記内の宝物情報を取得記録として使うので記録は消えません。

## ベータ版の制限

- 冒険の確定は18時以降に誰かが画面を開いた時点で実行します。18時のプッシュ通知はありません。準備した過去日分も、次回アクセス時に確定します。何もしなかった不在日の記録は作りません。
- ７つの既存の場所に新話を順次追加します。日替わりは `src/story-calendar.json` の日付別バージョンで固定し、過去と当日の設定は変更しません。新しい巡回は翌日以降から開始します。無限生成はしません。
- セッションは30日間です。全端末のCookie消去・セッション失効、PINの紛失に対する自動復旧は未実装です。一般向け本格公開前にアカウント復旧・エクスポート・家族データ削除を追加する予定です。
- メンバー単位の削除・並べ替え、時間帯設定、音声読み上げ、オフライン遊び、ネイティブストア配信は未実装。
- 家族内の絵日記は相互に閲覧できます。個人の秘密の日記としては扱いません。
- 物理スマホでのカメラ許可、iOS/Android双方の実機確認は別途必要です。

仕様: [docs/product.md](docs/product.md)

絵本調のキャラクター６種類を選べます。プロフィールから変更可能。おうちでは座る・のぞく・くつろぐ動作を２コマで表現し、停止ボタンと動きを減らす端末設定に対応しています。宝物とキャラクターはアルファ付きWebPです。

## 新話の追加

追加履歴は `docs/story-releases.json`、画像原画の対応表は `docs/story-art/`。同じ日本時間の日付は再開のみとし、重複して新話を作りません。画像は `node scripts/prepare-story-art.mjs docs/story-art/<ID>.json <原画ディレクトリ>` で再生成できます。冒険ごとの持ち物と行動は `src/adventure-equipment.json` で定義して絵日記に保存し、過去の行動は後から書き換えません。

持ち物の切替は2026-11-14（日本時間）から。サーバーも当日の冒険の６種類だけを受け付けます。旧６種は過去の準備・絵日記のために維持します。追加話では固有の６種類・６アイコン・６結果画像を作り、`adventure-equipment.json` に追加してください。原画対応表は `docs/equipment-art-sources.json`、切り出しは `scripts/prepare-equipment-art.mjs`。
