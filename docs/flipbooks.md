# 冒険のぱらぱら絵本

冒険ごとに５枚の専用静止画を順番に表示する。実動画生成なし。持ち物別の結果の絵は別に残す。

絵日記を開くと自動再生する。通常500ms、見せ場700〜800ms、最後3000ms。その後は最初へ戻りループする。停止・もう一度再生のボタンを付け、絵日記を閉じる／切り替える／アプリを背景にしたときは停止する。端末の「動きを減らす」が有効なら自動再生せず、本人の再生操作を待つ。

５枚を読み込んでから再生を開始し、失敗時には再試行できる。各話の間隔は `src/flipbook.js` の `timings` で調整する。

初期原画は３列２行のシート。左上から５コマを使用し、６コマ目は予備。`docs/flipbook-sources.json` と `scripts/prepare-flipbooks.mjs` から切り出す。追加話は `docs/story-art/<ID>.json` と `scripts/prepare-story-art.mjs` を使う。
