# 冒険のぱらぱら絵本

動画生成は使わず、冒険ごとに５枚の専用静止画を順番に表示する。持ち物によらず共通、既存の持ち物別42場面はそのまま残す。

基本間隔は500ms。宝物の出現などは700〜800ms、最終コマは1000ms見せ、そのまま停止する。５秒には引き延ばさない。各冒険の調整値は `src/flipbook.js` の `timings` に集約。

タップして１回再生・停止・再再生。自動再生やループなし。５枚を読み込んでから開始し、読み込み失敗時には再試行できる。絵日記を閉じる・切り替える・アプリが背景になると停止する。

原画は３列２行のシート。左上から５コマを使用し、６コマ目は予備。`docs/flipbook-sources.json` と `scripts/prepare-flipbooks.mjs` から配信用WebPを作る。
